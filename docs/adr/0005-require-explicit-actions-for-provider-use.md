# Require explicit actions for model-provider use

Uploading a CV, pasting a Job, or changing inputs processes data locally and does not itself trigger a model-provider call. Each provider-backed task requires an explicit user action with disclosure of its destination and data categories; configuring a key alone is not authorization. This trades automatic processing for control over when personal data leaves the device.

Manual structured Job entry, deterministic checks, Evidence entry, and Application tracking remain available without a model. A portable data export is provided, but is not represented as a tested backup or restore workflow.
