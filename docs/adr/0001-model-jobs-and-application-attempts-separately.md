# Model jobs and application attempts separately

A Job is an opening that can be saved without an Application; an Application records one attempt, and multiple attempts can refer to the same Job. This preserves reapplication history and avoids treating every bookmarked opening as an attempt, at the cost of managing two related records. Identical job-description text warns of a possible duplicate but does not establish identity or prevent another Job.

An Application records the submitted CV version when known, independently of the current default. Its history reflects actual status changes, including skipped stages and corrections, while its Job details show current corrections rather than a frozen copy.
