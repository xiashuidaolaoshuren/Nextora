# Show evidence mappings instead of a fit band

The core presents requirement-level Evidence Fit mappings instead of an aggregate band or percentage. This keeps the basis of the assessment visible and avoids implying that unvalidated weights and thresholds can summarize a Candidate's suitability. A failed or invalid assessment is unable to assess, not a finding that no supporting evidence exists.

Only confirmed Candidate evidence may be cited. Changed inputs make mappings stale; a fresh model-assisted assessment requires an explicit user action.
