# Separate advisory eligibility from preferences

Eligibility compares explicit Job conditions against relevant self-reported Candidate facts; Preference Match compares the Job against what the Candidate wants. We keep these assessments separate so an unwanted work mode or salary does not imply the Candidate is ineligible, and neither assessment blocks recording an Application.

Checks are deterministic and conservative: missing or ambiguous facts yield unknown. An unreviewed model-extracted condition may fail only when its source quote is verbatim and deterministic recognition establishes the condition. Results are advisory, not legal or hiring decisions.

Permanent residency, current Work Permission, and Sponsorship to Start are separate self-reported facts. The Hong Kong permanent-resident shortcut confirms them together explicitly rather than inferring permission or sponsorship from residency or a visa label. This keeps the common path short without treating employer help needed to start as the same as possible help with a future extension.

Explicit graduation windows and mandatory caps on total full-time work experience are Eligibility conditions, not proxies for Career Stage. The assessment shows the reference date for a relative graduation window so that any fallback to the assessment date is visible.
